Gleichungssysteme · Addieren

alle Übungen des Arbeitsblatts — dazu Extra-Aufgaben und Sonderfälle

Rechnen Sie im Hefter mit dem Additionsverfahren: Gleichungen so vervielfachen, dass vor einer Variablen Gegenzahlen stehen, dann addieren — die Variable fällt weg. Notieren Sie jede Umformung rechts, z. B. II · 3 → II′ und I + II′ → III. Stehen gleiche Zahlen da, dürfen Sie auch subtrahieren (I − II → III). Probe in beiden Gleichungen, dann die Lösungsmenge. Tragen Sie hier nur das Ergebnis ein — meist ein Zahlenpaar wie (3;2). Bei den Sonderfällen am Ende ist die Antwort L = { } oder eine Bedingung wie L = {(x;y) | y = x+2}. Zu jeder Aufgabe gibt es einen Tipp zum ersten Schritt, einen weiteren Hinweis und den vollständigen Lösungsweg mit Probe.

(5/2;10/3)Brüche mit Schrägstrich und exakt: 3,33 gilt nicht als Lösung.
(-2;-3)Negative Werte mit Minus davor.
L = { }  ·  keine LösungDer Sonderfall falsche Aussage (z. B. 0 = 2): Es gibt kein Zahlenpaar, die Geraden sind parallel.
L = {(x;y) | y = x+2}Der Sonderfall wahre Aussage (z. B. 0 = 0): unendlich viele Lösungen, die Geraden sind identisch. Geprüft wird die Gerade, nicht der Wortlaut — x = y − 2 gilt genauso wie y = x + 2.

Nach dem Prüfen steht unter dem Feld, wie Ihre Eingabe gelesen wurde. Steht dort etwas anderes, als Sie meinen, fehlt meist das Semikolon oder eine Klammer.

Fragen Sie nach, wenn Sie feststecken gibt keine Lösungen preis
Öffnen Sie einen Hinweis erst, wenn Sie selbst nicht mehr weiterkommen. Der Lernbegleiter verrät die Lösung nicht — auch nicht auf Umwegen.
Geprüft wird durch Einsetzen in beide Gleichungen: Genau das ist die Probe, die Sie im Hefter auch von Hand machen.
